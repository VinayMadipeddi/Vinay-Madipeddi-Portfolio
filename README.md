# Vinay Madipeddi — Portfolio

A responsive, animated static portfolio inspired by the editorial/minimal visual language of the supplied reference video.

## Run
Open `index.html` directly in a browser, or use a local server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Personal links
The GitHub and LinkedIn buttons are intentionally placeholders because their exact profile URLs were not provided. Replace the `href="#"` values in `index.html`.

## Files
- `index.html` — content and structure
- `styles.css` — layout, typography, responsive design and animations
- `script.js` — small interactions
- `assets/vinay-toon.png` — transparent-background toon extracted from the uploaded image
